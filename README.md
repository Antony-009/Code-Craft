# **CodeCraft** ✨  
**Visualize. Learn. Build.**

An **interactive web platform** designed to help you **understand complex concepts** in:

- 🧠 **Data Structures & Algorithms (DSA)**  
- 🤖 **AI Algorithms**  
- 🌐 **Networking Protocols**

Through **real-time visualizations** and **intuitive simulations**, CodeCraft makes learning **fun, visual, and interactive**.

Built with **Next.js**, **JavaScript**, and **modern web technologies**.

Try Here: **https://codecraft-fawn-gamma.vercel.app/**
---

## 🌟 Features

### 🧩 Data Structures & Algorithms
Visualize how DSA works **step-by-step**:

- **Data Structures**: Arrays, Linked Lists, Stacks, Queues, Trees, Graphs  
- **Sorting Algorithms**: Bubble, Merge, Quick, Heap, etc.  
- **Searching Algorithms**: Linear, Binary  
- **Pathfinding**: Dijkstra, BFS, DFS  
- **Real-time Visualization**: Watch every operation happen **live!**

---

### 🤖 AI Algorithm Visualizer
Understand AI logic **visually**:

- **Algorithms**: A*, Minimax, Alpha-Beta Pruning, Genetic Algorithm, etc.  
- **Customizable Parameters**: Adjust speed, heuristics, and iterations  
- **Live Decision-Making**: Watch the algorithm **think and decide** in real-time

---

### 🌐 Networking Protocol Simulations
Explore how data travels through a network:

- **Protocols**: TCP/IP, HTTP, DNS, DHCP, ARP  
- **Visualizations**: Packet transfers, request/response cycles, handshakes

---

## 🛠️ Tech Stack

| Technology           | Purpose                                  |

## 💻 Installation

Follow these simple steps to get CodeCraft running locally 👇

---

### 🔹 Step 1: Clone the Repository

```bash
git clone https://github.com/your-username/codecraft.git
cd codecraft
```

---

### 🔹 Step 2: Install Dependencies

```bash
npm install
# or
yarn install
```

---

### 🔹 Step 3: Run the Development Server

```bash
npm run dev
```

---

### 🔹 Step 4: Open in Your Browser

👉 [http://localhost:3000](http://localhost:3000)
